# เอกสารตรวจกฎ (สร้างอัตโนมัติ จากกฎและไฟล์ข้อมูลที่รันอยู่จริง)

สถานะ: **DRAFT — ยังไม่ผ่านการตรวจทานโดยแพทย์**  ·  เวอร์ชันข้อมูล: 0.1-draft

> ห้ามใช้กับผู้ป่วยจริงจนกว่าแพทย์จะตรวจทุกข้อด้านล่างและลงนามรับรอง แก้เกณฑ์ที่ `data/targets.json` แก้ถ้อยคำที่ `data/templates.json` แก้คำสงฆ์ที่ `data/glossary.json` แล้วรัน `python3 tools/dump_rules.py` เพื่อสร้างเอกสารนี้ใหม่ และ `python3 -m unittest discover -s tests -t .` เพื่อตรวจว่าไม่มีอะไรพัง

## 1. คำถามที่ต้องให้แพทย์ตัดสินใจ

- [ ] **ค่าที่ขอบเกณฑ์:** ระบบใช้ "ต่ำกว่า" (<) เสมอ เช่น เป้า BP < 130/80 แล้วค่าล่าง 80 ถือว่า **ยังไม่ถึงเป้าหมาย** (ข้อความใช้คำว่า "ยังไม่ถึงเป้าหมาย" ไม่ใช่ "สูงกว่า") เห็นด้วยหรือไม่
- [ ] **BP เป้าหมายเข้มขึ้นเป็น < 130/80 เมื่อบันทึกมี DM หรือ CKD** (ทั้ง BP คลินิกและที่บ้าน) ใช้ตามนี้ไหม หรือใช้ < 140/90 เสมอ
- [ ] **เป้า HbA1c เดียว (≤ 7.0%) สำหรับทุกคน** ผู้สูงอายุ/เปราะบางมักใช้เป้าหลวมกว่า ต้องการให้มีเป้าตามกลุ่มหรือกรอกเป้าเป็นรายคนหรือไม่
- [ ] **ความดันที่บ้าน 135/85 (ทั่วไป)** และเกณฑ์ white-coat / masked ใช้ค่าตามที่ตั้งไว้ถูกหรือไม่
- [ ] **HbA1c ลดรวม ≥ 2 จุด** เป็นเกณฑ์เตือนแพทย์เรื่องน้ำตาลต่ำ (ไม่ทราบช่วงเวลาระหว่างค่า เพราะบันทึกไม่มีวันที่ต่อค่า) เหมาะสมหรือไม่
- [ ] **ข้อสังเกต 'DM + เวียนศีรษะ/ใจสั่น + รับประทานได้น้อยลง'** ถ้อยคำเหมาะสมหรือไม่ (ข้อความนี้แสดงเฉพาะแพทย์ ไม่พิมพ์ให้ผู้ป่วย)
- [ ] **ค่า eGFR ที่ระบบคำนวณเอง** (เมื่อไม่มี eGFR แต่มี Cr + อายุ + เพศ) ใช้ CKD-EPI 2021 ถูกต้องตามที่ รพ. ใช้หรือไม่ และข้อความระบุว่า "(คำนวณโดยระบบ)"
- [ ] **BMI เกณฑ์คนเอเชีย** (23 / 25 / 30) และ **น้ำหนักเปลี่ยน ≥ 5%** ถือว่ามีนัย ใช้ได้หรือไม่
- [ ] **คำสงฆ์ในไฟล์ glossary.json** (เช่น "อดอาหาร" → "งดภัตตาหาร", "ออกกำลังกาย" → "เดินจงกรม", "น้ำดื่ม" → "น้ำปานะ") และข้อความวิถีสงฆ์สองข้อ ตั้งต้นจากรายการในรีโปเดิมของแพทย์ ต้องให้ผู้ที่เชี่ยวชาญตรวจ
- [ ] **เบอร์สายด่วนเลิกบุหรี่ (1600)** ตรวจสอบว่ายังใช้ได้ก่อนใช้งานจริง
- [ ] **คำแนะนำทั่วไปต่อโรค** (หัวข้อ 4) ครบและเหมาะสมหรือไม่ มีอะไรที่ไม่ควรมีหรือขาดไป
- [ ] **เป้า LDL: 130 (ทั่วไป) และ 100 (เมื่อบันทึกมี DM/CKD)** ระบบยังไม่รู้ว่าผู้ป่วยมี ASCVD หรือไม่ (เป้าจะต่ำกว่านี้) ต้องการช่องให้ระบุความเสี่ยงหรือไม่ · เกณฑ์ TG / HDL / TC ตามตารางหัวข้อ 3 ใช้ได้หรือไม่
- [ ] **Thai CV risk:** ระบบ **ไม่คำนวณ** (สมการไม่ได้เผยแพร่ในแหล่งที่ตรวจสอบได้ และเงื่อนไขของเครื่องมือรามาธิบดีจำกัดการใช้) มีเพียงช่องให้กรอกค่า % ที่ได้จากเครื่องมือเอง (ใช้ออฟไลน์ได้) แบ่งกลุ่ม <10 / 10-<20 / 20-<30 / ≥30 และมีรายการตรวจว่าบันทึกมีข้อมูลครบไหม (อายุ เพศ สูบบุหรี่ SBP และ TC/BMI/รอบเอว อย่างน้อยหนึ่ง; เบาหวานถือว่าไม่เป็นถ้าไม่เขียน DM) ตรวจรายการนี้กับเครื่องมือเวอร์ชันที่ใช้จริง และเกณฑ์ขอบเขต 30 · ถ้าต้องการให้คำนวณเอง ต้องมีสมการต้นฉบับ/ใบอนุญาต และกรณีทดสอบจากเครื่องมือจริง
- [ ] **DN / KDIGO:** UACR (หรือ urine microalbumin UMA ที่ **ต้องเขียนหน่วย mg/g**) A1 < 30, A2 ถึง 300, A3 มากกว่า · ตารางความเสี่ยง KDIGO (G x A) แสดงเฉพาะแพทย์ · ข้อความ 'ต้องตรวจซ้ำเพื่อยืนยัน' เหมาะสมหรือไม่
- [ ] **U/S KUB (ในบรรทัด CKD):** คำที่ระบบรู้อยู่ใน `data/lexicon.json` หมวด tags (echo เพิ่ม, ไตเล็ก, hydronephrosis, นิ่ว, ก้อน, cyst, ไม่เท่ากัน, ปกติ) 'no hydro' = ไม่มี · ก้อน = ระดับแจ้งเตือน ถ้อยคำเหมาะสมหรือไม่ มีคำที่ใช้บ่อยแต่ขาดไปหรือไม่
- [ ] **DR:** ระดับ (no DR, NPDR mild/moderate/severe, PDR, DME, เคยรักษา) อ่านจากข้อความในบรรทัด `DR :` · ระบบไม่บอกความถี่ในการตรวจตา และเตือนแพทย์เมื่อ DM ไม่มีผลตรวจตาในบันทึก
- [ ] **MAFLD:** ค่าสูงสุดปกติ ALT/AST ตั้งต้น 40 U/L (ควรใช้ค่าของห้องแล็บ รพ. และอาจแยกเพศ) · FIB-4 คำนวณเอง เกณฑ์ 1.3 / 2.67 (อายุ ≥ 65 ใช้ 2.0) ไม่ใช้ถ้าอายุ < 35 · Fibroscan LSM 8 / 12 kPa และ CAP 248 / 268 / 280 dB/m (เกณฑ์ต่างกันตามรุ่นเครื่อง/probe และงานวิจัย) ใช้ชุดไหน · ระบบไม่ทราบคุณภาพการตรวจ Fibroscan
- [ ] **CAD / Stroke:** เป้า LDL เมื่อเป็น CAD หรือ Stroke ชนิดขาดเลือดใช้ 70 (Stroke ที่ไม่ระบุชนิดหรือเลือดออกจะ **ไม่** ใช้) · เป้า BP < 130/80 เมื่อมี CAD/Stroke/DN · เตือนแพทย์เมื่อบันทึกไม่ระบุ statin/ยาต้านเกล็ดเลือด (ไม่ได้แปลว่าไม่ได้รับ) · EF ≤ 40 ลดลง, ≤ 49 ลดลงเล็กน้อย · mRS แสดงเฉพาะแพทย์
- [ ] **COPD / Asthma:** GOLD 1-4 ตาม FEV1 % (80/50/30) และต้องมี FEV1/FVC < 0.7 · กลุ่ม A/B/E (mMRC ≥ 2 หรือ CAT ≥ 10; E = กำเริบ ≥ 2 หรือนอน รพ. ≥ 1) แสดงเฉพาะแพทย์ · SpO2 ใน COPD ไม่บอกผู้ป่วยว่าต่ำ ยกเว้น ≤ 88% · ACT 20/16 และโซน PEF 80/50% ใช้ได้หรือไม่
- [ ] **รอบเอวคนเอเชีย** ชาย ≥ 90 / หญิง ≥ 80 ซม. และ BMI คำนวณจาก BW + Height เมื่อไม่มี BMI (ระบุว่า 'คำนวณโดยระบบ')
- [ ] **ภาวะซีด:** ใช้เกณฑ์ WHO แยกตามเพศ (ชาย < 13, หญิง < 12) และ **ไม่แปล Hb ถ้าไม่ระบุเพศ** ยังไม่แยกตั้งครรภ์/ผู้สูงอายุ/ผู้ป่วย CKD ต้องการหรือไม่ · ดัชนี Mentzer และการตรวจความสอดคล้อง MCV, Hct, RBC แสดงเฉพาะแพทย์
- [ ] **วาฟาริน/INR:** ถ้าไม่ระบุ `goal` ใช้เป้า 2.0-3.0 แล้วบอกแพทย์ · INR ≥ 4.5 (และสูงกว่าเป้า) ถือว่าสูงมาก · ระบบ **ไม่แนะนำขนาดยาและไม่ให้ผู้ป่วยปรับยา** · ข้อสังเกต 'รับประทานได้น้อยลง → INR อาจสูงขึ้น' เหมาะสมหรือไม่ · ถ้ามีคลินิกวาฟารินแยกอยู่แล้ว ต้องการให้ระบบนี้ครอบคลุม INR หรือไม่

## 2. กฎทั้งหมด

| รหัสกฎ | กลุ่ม | ทำอะไร |
|---|---|---|
| `dm.hba1c.status` | DM | HbA1c ล่าสุด ≤ 7.0 = อยู่ในเป้า; < 8.0 = สูงกว่าเป้าเล็กน้อย; < 10.0 = สูงกว่าเป้า; ≥ 10.0 = สูงมาก (ระดับแจ้งเตือน) |
| `dm.hba1c.trend` | DM | ถ้ามีหลายค่า: ล่าสุด − แรกสุด ≤ -0.5 = ดีขึ้น; ≥ +0.5 = แย่ลง; ที่เหลือ = ใกล้เคียงเดิม |
| `dm.hba1c.rapid_drop` | DM | [เฉพาะแพทย์] HbA1c ลดลงรวม ≥ 2.0 จุด (ไม่ทราบช่วงเวลาระหว่างค่า) |
| `dm.fbs.status` | DM | FBS ล่าสุด < 70 = ต่ำ (แจ้งเตือน); < 80 = ค่อนข้างต่ำ; 80-130 = อยู่ในเป้า; < 180 = สูงกว่าเป้า; ≥ 180 = สูงมาก (แจ้งเตือน) |
| `ht.clinic.status` | HT | BP คลินิกล่าสุด: เป้า < 140/90 (< 130/80 ถ้าบันทึกว่ามี DM หรือ CKD); ≥ 180 หรือ ≥ 120 = วิกฤต (แจ้งเตือน) |
| `ht.home.status` | HT | BP ที่บ้านล่าสุด: เป้า < 135/85 (< 130/80 ถ้าบันทึกว่ามี DM หรือ CKD) |
| `ht.discordance` | HT | BP คลินิก ≥ 140/90 แต่บ้าน < 135/85 → เข้าได้กับ white-coat; กลับกัน → masked (ให้แพทย์ตัดสิน) |
| `ob.bmi.class` | Obesity | BMI (เกณฑ์เอเชีย) < 18.5 น้ำหนักต่ำ; < 23.0 ปกติ; < 25.0 น้ำหนักเกิน; < 30.0 อ้วนระดับ 1; มากกว่านั้น อ้วนระดับ 2 |
| `ob.weight.change` | Obesity | น้ำหนักเปลี่ยนจากค่าแรกสุดถึงล่าสุด ≥ 5.0% ถือว่ามีนัย (ลด/เพิ่ม) |
| `ckd.egfr.stage` | CKD | eGFR ≥ 90 G1; ≥ 60 G2; ≥ 45 G3a; ≥ 30 G3b; ≥ 15 G4; ต่ำกว่านั้น G5 (ถ้าไม่มี eGFR แต่มี Cr + อายุ + เพศ จะคำนวณ CKD-EPI 2021 และระบุว่าคำนวณโดยระบบ) |
| `ckd.egfr.trend` | CKD | eGFR ล่าสุดต่างจากค่าแรกสุด ≥ 10 (ลด = แย่ลง, เพิ่ม = ดีขึ้น) |
| `ckd.crosscheck` | CKD | [เฉพาะแพทย์] เทียบ eGFR ที่ระบุกับค่าคำนวณ CKD-EPI 2021 จาก Cr + อายุ + เพศ: ต่างเกิน 15% และเกิน 5 หน่วย = ตรวจสอบ |
| `ckd.albuminuria_missing` | CKD | [เฉพาะแพทย์] มี CKD ในบันทึกแต่ไม่มีค่า UACR → แจ้งว่าจัดระยะ albuminuria (A) ไม่ได้ |
| `dm.uacr_missing` | DM | [เฉพาะแพทย์] มี DM ในบันทึก (ไม่มี CKD/DN) แต่ไม่มีค่า UACR → แจ้งว่าไม่มีข้อมูลคัดกรองไตจากเบาหวาน |
| `life.smoking` | Today | บรรทัดวันที่ล่าสุดบอกว่า 'ยังสูบบุหรี่' → ข้อความให้ความรู้เรื่องเลิกบุหรี่ (เบอร์สายด่วนจาก targets.json); 'เลิกแล้ว' → ข้อความชื่นชม |
| `life.symptoms` | Today | บรรทัดวันที่ล่าสุดมีอาการ (เวียนศีรษะ บ้านหมุน ปวดศีรษะ ใจสั่น บวม เหนื่อย) → แนะนำให้แจ้งแพทย์/พยาบาล (ไม่สรุปสาเหตุ) |
| `life.intake` | Today | บรรทัดวันที่ล่าสุดบอกว่ารับประทานได้น้อยลง → แนะนำให้แจ้งแพทย์/พยาบาล |
| `xr.dm_hypo` | Today | [เฉพาะแพทย์] มี DM ในบันทึก + (เวียนศีรษะ หรือ ใจสั่น) + รับประทานได้น้อยลง → เตือนให้พิจารณาภาวะน้ำตาลต่ำและยาที่ใช้ (ไม่ตัดสิน) |
| `dlp.ldl.status` | Dyslipidemia | LDL ล่าสุด < เป้า = อยู่ในเป้า (เป้า 130; 100 ถ้าบันทึกว่ามี DM หรือ CKD); ไม่เกินเป้า + 30 = ใกล้เป้า; มากกว่านั้น = สูงกว่าเป้า; ≥ 190 = สูงมาก (แจ้งเตือน) [เฉพาะแพทย์: เตือนว่าเป้า LDL จริงขึ้นกับความเสี่ยง ASCVD ซึ่งบันทึกไม่ได้ระบุ] |
| `dlp.ldl.trend` | Dyslipidemia | ถ้ามีหลายค่า: LDL ล่าสุดเทียบค่าแรกสุดลด ≥ 15% = ดีขึ้น; เพิ่ม ≥ 15% = แย่ลง |
| `dlp.tg.status` | Dyslipidemia | TG ล่าสุด < 150 ปกติ; < 200 ค่อนข้างสูง; < 500 สูง; ≥ 500 สูงมาก (แจ้งเตือน เสี่ยงตับอ่อนอักเสบ) |
| `dlp.hdl.status` | Dyslipidemia | HDL ล่าสุด ต่ำกว่า 40 (ชาย) / 50 (หญิง) = ต่ำ (ถ้าไม่ระบุเพศ ใช้เกณฑ์ผู้ชายและบอกแพทย์) |
| `dlp.tc.status` | Dyslipidemia | TC ล่าสุด < 200 ที่ต้องการ; < 240 ค่อนข้างสูง; มากกว่านั้น สูง |
| `anemia.hb.status` | Anemia | Hb ล่าสุด: ซีดเมื่อ < 13.0 (ชาย) / < 12.0 (หญิง); เล็กน้อย ≥ 11.0; ปานกลาง ≥ 8.0; รุนแรง ต่ำกว่านั้น (แจ้งเตือน) — **ต้องระบุเพศ** ถ้าไม่ระบุจะไม่แปลผล Hb และบอกแพทย์ (ไม่ได้แยกตั้งครรภ์/ผู้สูงอายุ) |
| `anemia.hb.trend` | Anemia | ถ้ามีหลายค่า: Hb ล่าสุดต่างจากค่าแรกสุด ≥ 1.0 g/dL (เพิ่ม = ดีขึ้น, ลด = แย่ลง) |
| `anemia.mcv.class` | Anemia | MCV ล่าสุด < 80 เม็ดเลือดแดงเล็ก; > 100 ใหญ่; ที่เหลือปกติ |
| `anemia.mentzer` | Anemia | [เฉพาะแพทย์] MCV < 80 และมี RBC: Mentzer = MCV/RBC; < 13 เข้าได้กับ thalassemia trait, ≥ เกณฑ์ เข้าได้กับขาดธาตุเหล็ก (ประกอบเท่านั้น) |
| `anemia.rdw` | Anemia | [เฉพาะแพทย์] RDW ล่าสุด > 14.5% = สูง |
| `anemia.crosscheck` | Anemia | [เฉพาะแพทย์] ตรวจการพิมพ์ผิด: MCV ที่ระบุต่างจาก Hct/RBC×10 เกิน 10%; Hct/Hb อยู่นอก 2.7-3.3 |

## 4. คำแนะนำและสัญญาณอันตรายที่พิมพ์ให้ผู้ป่วย

**เบาหวาน**
- {ทาน}{อาหาร}ตามที่แพทย์หรือนักโภชนาการแนะนำ ลดน้ำตาลและของหวาน
- ตรวจติดตามน้ำตาลและ HbA1c ตามที่แพทย์นัด
- ดูแลและตรวจเท้าของตนเองสม่ำเสมอ

**ความดันโลหิตสูง**
- ลดเกลือและ{อาหาร}รสเค็ม
- วัดความดันที่บ้านตามที่แพทย์แนะนำ และจดบันทึกมาให้แพทย์ดู

**น้ำหนักและโรคอ้วน**
- ควบคุม{อาหาร}และปริมาณที่{ทาน}ในแต่ละมื้อ
- {ออกกำลัง}อย่างสม่ำเสมอเท่าที่{กาย}ทำได้ และ{นอน}ให้เพียงพอ

**โรคไตเรื้อรัง**
- หลีกเลี่ยงยาแก้ปวดกลุ่ม NSAIDs ยาสมุนไพร และอาหารเสริม โดยไม่ปรึกษาแพทย์หรือเภสัชกร
- ควบคุมน้ำตาลและความดันให้อยู่ในเป้าหมายเพื่อชะลอการเสื่อมของไต

**General**
- ห้ามปรับหรือหยุดยาเอง
- มาตรวจติดตามตามที่แพทย์นัด

**ไขมันในเลือด**
- ลด{อาหาร}มัน ของทอด และไขมันอิ่มตัว
- เพิ่มผัก ผลไม้ และของที่มีเส้นใยสูง
- {ออกกำลัง}อย่างสม่ำเสมอเท่าที่{กาย}ทำได้
- หากแพทย์จ่ายยาลดไขมัน ให้{ทาน}ต่อเนื่อง ห้ามหยุดเอง

**ภาวะซีด / เม็ดเลือดแดง**
- ให้แพทย์ตรวจหาสาเหตุของภาวะซีดก่อน ไม่ควรซื้อยาบำรุงเลือดหรืออาหารเสริมมา{ทาน}เอง
- {ทาน}{อาหาร}ให้ครบหมู่ตามที่แพทย์หรือนักโภชนาการแนะนำ

**การใช้ยาวาฟาริน (ค่า INR)**
- {ทาน}ยาวาฟารินตามที่แพทย์สั่ง เวลาเดิมทุกวัน ห้ามปรับหรือหยุดยาเอง
- {ทาน}ผักใบเขียวในปริมาณใกล้เคียงกันทุกสัปดาห์ ไม่งดและไม่เพิ่มมากผิดปกติ
- แจ้งแพทย์หรือเภสัชกรก่อนเริ่มยา สมุนไพร หรืออาหารเสริมใหม่ทุกชนิด
- มาตรวจเลือด INR ตามที่แพทย์นัด

**ไตจากเบาหวาน**
- ควบคุมน้ำตาลและความดันให้ได้ตามเป้าเพื่อชะลอการเสื่อมของไต
- หลีกเลี่ยงยาแก้ปวดกลุ่ม NSAIDs ยาสมุนไพร และอาหารเสริม โดยไม่ปรึกษาแพทย์หรือเภสัชกร
- ตรวจปัสสาวะหาอัลบูมินและเลือดดูการทำงานของไตตามที่แพทย์นัด

**จอประสาทตาจากเบาหวาน**
- ตรวจจอประสาทตากับจักษุแพทย์ตามนัดอย่างสม่ำเสมอ แม้ยังมองเห็นปกติ
- ควบคุมน้ำตาลและความดันให้ได้ตามเป้าเพื่อชะลอเบาหวานขึ้นตา

**ตับและไขมันพอกตับ**
- ค่อย ๆ ลดน้ำหนักถ้าน้ำหนักเกิน โดยควบคุม{อาหาร}หวาน มัน และของทอด
- {ออกกำลัง}อย่างสม่ำเสมอเท่าที่{กาย}ทำได้
- ไม่ซื้อยา สมุนไพร หรืออาหารเสริมมา{ทาน}เอง เพราะอาจทำให้ตับอักเสบ
- ควบคุมน้ำตาล ไขมัน และความดันให้ได้ตามเป้า

**โรคหลอดเลือดหัวใจ**
- {ทาน}ยาที่แพทย์จ่ายให้ต่อเนื่อง ห้ามหยุดยาเอง
- งดสูบบุหรี่ และควบคุมความดัน ไขมัน และน้ำตาลให้ได้ตามเป้า
- {ออกกำลัง}เบา ๆ สม่ำเสมอตามที่แพทย์อนุญาต

**โรคหลอดเลือดสมอง**
- {ทาน}ยาที่แพทย์จ่ายให้ต่อเนื่อง ห้ามหยุดยาเอง
- ควบคุมความดัน ไขมัน และน้ำตาลให้ได้ตามเป้า และงดสูบบุหรี่
- ญาติและผู้ดูแลควรรู้สัญญาณหลอดเลือดสมอง (ปากเบี้ยว แขนขาอ่อนแรง พูดไม่ชัด) และรีบนำส่งโรงพยาบาลทันที

**โรคปอดอุดกั้นเรื้อรัง (COPD)**
- ใช้ยาพ่นถูกวิธีและต่อเนื่องตามที่แพทย์สั่ง ถ้าไม่แน่ใจวิธีพ่นให้ขอให้พยาบาลหรือเภสัชกรสอนซ้ำ
- งดสูบบุหรี่ และหลีกเลี่ยงควัน ฝุ่น และมลพิษ
- ฉีดวัคซีนป้องกันปอดอักเสบและไข้หวัดใหญ่ตามที่แพทย์แนะนำ
- {ออกกำลัง}และฝึกการหายใจตามที่แพทย์หรือนักกายภาพบำบัดแนะนำ

**โรคหืด**
- ใช้ยาพ่นควบคุมโรคหืดต่อเนื่องแม้ไม่มีอาการ ตามที่แพทย์สั่ง
- หลีกเลี่ยงสิ่งกระตุ้น เช่น ควัน ฝุ่น ละอองเกสร และอากาศเย็นจัด
- พกยาพ่นฉุกเฉินติดตัวเสมอ และทำตามแผนการดูแลโรคหืดที่แพทย์ให้

**สัญญาณที่ต้องมาพบแพทย์ทันที**
- เบาหวาน: ใจสั่น เหงื่อออกมาก หน้ามืด ซึม สับสน (อาจเป็นน้ำตาลต่ำ) หรือกระหายน้ำมาก ปัสสาวะบ่อยมาก อ่อนเพลียมาก
- ความดันโลหิตสูง: ปวดศีรษะรุนแรง เห็นภาพซ้อน ชาหรืออ่อนแรงครึ่งซีก พูดไม่ชัด เจ็บหน้าอก
- โรคไตเรื้อรัง: ปัสสาวะออกน้อยมาก บวมเพิ่มขึ้นมาก หายใจเหนื่อย คลื่นไส้อาเจียนมาก ซึม
- General: หากมีอาการรุนแรงหรือผิดปกติอื่นใด ให้มาโรงพยาบาลทันที
- ไขมันในเลือด: เจ็บแน่นหน้าอก เหนื่อยง่ายผิดปกติ ปวดท้องรุนแรง
- ภาวะซีด / เม็ดเลือดแดง: เหนื่อยง่ายมาก ใจสั่น หน้ามืดเป็นลม ถ่ายอุจจาระสีดำหรือเป็นเลือด
- การใช้ยาวาฟาริน (ค่า INR): เลือดออกที่หยุดยาก เลือดกำเดาไหลนาน ถ่ายดำ ปัสสาวะเป็นเลือด ปวดศีรษะรุนแรงโดยเฉพาะหลังล้มหรือศีรษะกระแทก
- ไตจากเบาหวาน: ปัสสาวะออกน้อยมาก บวมมากขึ้น หายใจเหนื่อย คลื่นไส้อาเจียนมาก ซึม
- จอประสาทตาจากเบาหวาน: ตามัวลงทันที เห็นเงาดำหรือม่านบังตา เห็นแสงวาบหรือจุดดำลอยมากขึ้น
- ตับและไขมันพอกตับ: ตัวเหลืองตาเหลือง ท้องบวมใหญ่ อาเจียนเป็นเลือด ถ่ายดำ สับสนหรือซึม
- โรคหลอดเลือดหัวใจ: เจ็บหรือแน่นหน้าอก ร้าวไปแขนหรือกราม เหนื่อยหอบ เหงื่อแตก ใจสั่นรุนแรง หน้ามืดเป็นลม
- โรคหลอดเลือดสมอง: ปากเบี้ยว แขนขาอ่อนแรงหรือชาครึ่งซีก พูดไม่ชัด มองไม่เห็นกะทันหัน ปวดศีรษะรุนแรงฉับพลัน
- โรคปอดอุดกั้นเรื้อรัง (COPD): เหนื่อยหอบมากขึ้นผิดปกติ ริมฝีปากหรือปลายนิ้วเขียว เสมหะเปลี่ยนสีหรือมีเลือดปน ซึมหรือสับสน
- โรคหืด: หอบเหนื่อยมากจนพูดเป็นประโยคไม่จบ ใช้ยาพ่นฉุกเฉินแล้วไม่ดีขึ้น ริมฝีปากเขียว ซึม

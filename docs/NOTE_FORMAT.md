# รูปแบบบันทึกที่ระบบอ่านได้

## หลักการ
- **ซ้ายสุด = เก่าสุด · ขวาสุด = ล่าสุด** ในชุดค่า (`HbA1c 12->10->6.5` ล่าสุดคือ 6.5)
- ระบบ **ไม่เดา** ส่วนที่ไม่เข้าใจจะแสดงเป็น "ไม่เข้าใจ" ให้ผู้ตรวจดู ค่าที่เป็นไปไม่ได้จะถูก **ข้าม ไม่แปลผล** พร้อมเตือน

## 1) บรรทัดปัญหา: `ชื่อปัญหา : ค่า ค่า ...`
```
DM : FBS 120->130->110 HbA1C 12->10->6.5%
HT : BP 150/90mmHg HMBP 120/80mmHg
Obesity : BW 110-->100Kg BMI 31
CKD : Cr 1.5 GFR 54
```
| สิ่งที่รองรับ | ตัวอย่าง |
|---|---|
| ลูกศรแบบต่าง ๆ | `->` `-->` `--->` `=>` `→` `⇒` |
| ตัวพิมพ์เล็ก/ใหญ่ | `hba1c` `HbA1C` `Hba1c` |
| ชื่อเรียกอื่น | `T2DM` `HTN` `Obese` · `fpg` `a1c` · `wt` `weight` `น้ำหนัก` |
| เลขไทย และ `：` | `๑๒->๑๐` |
| หน่วย (ไม่บังคับ) | `%` `mmHg` `Kg` `mg/dL` |
| แปลงหน่วยอัตโนมัติ (มีเตือนบอก) | FBS mmol/L · HbA1c mmol/mol · Cr µmol/L |
| ความดัน | `150/90` (บน/ล่าง) ชุดค่า: `150/90->140/85` |

ค่าที่อ่านได้และมีกฎแปลผล:

| กลุ่ม | ชื่อบรรทัด (ตัวอย่าง) | ค่า |
|---|---|---|
| เบาหวาน | `DM` `T2DM` | FBS, HbA1c |
| ความดันสูง | `HT` `HTN` | BP, HMBP (ที่บ้าน) |
| น้ำหนัก/โรคอ้วน | `Obesity` | BW, BMI |
| โรคไต | `CKD` `KUB` | Cr, eGFR (`GFR`), UACR · ผลอัลตราซาวด์ไตเขียนเป็นข้อความในบรรทัดเดียวกัน เช่น `U/S KUB increased echo, no hydro` |
| เบาหวานลงไต | `DN` (เขียนรวมได้ `DM/DN`) | UACR หรือ `UMA 40 mg/g` (**UMA ต้องมีหน่วย mg/g** ถ้าเป็น mg/L หรือไม่มีหน่วย ระบบข้ามและแจ้งเตือน) |
| เบาหวานขึ้นตา | `DR` | ข้อความ: `no DR` `NPDR mild/moderate/severe` `PDR` `DME` `laser` |
| ตับ/MAFLD | `MAFLD` `NAFLD` `ตับ` | ALT, AST, Plt (เขียน `180` หรือ `180000`), LSM/Fibroscan (kPa), CAP (dB/m) · ระบบคำนวณ FIB-4 เอง (ต้องกรอกอายุ) |
| หัวใจ | `CAD` | LVEF (`EF`) · ข้อความ: `PCI` `stent` `CABG` `MI` `statin` `ASA` |
| หลอดเลือดสมอง | `Stroke` | mRS · ข้อความ: `ischemic` `TIA` `hemorrhagic` (ต้องระบุชนิด) |
| ปอดอุดกั้น | `COPD` | FEV1 (% ของค่าคาดหวัง), `FEV1/FVC 0.62` หรือ `62%`, mMRC, CAT, Exac (ครั้งกำเริบใน 1 ปี), ExacHosp (ครั้งที่นอน รพ.), SpO2 |
| หืด | `Asthma` | ACT, PEF + PEFbest, Exac |
| รอบเอว/ส่วนสูง | `Obesity` | Waist (ซม., ต้องกรอกเพศ), Height (ซม., ใช้คำนวณ BMI เมื่อไม่มี BMI) |
| ไขมันในเลือด | `DLP` `lipid` | LDL, HDL, TG, TC |
| ภาวะซีด/CBC | `Anemia` `CBC` `ซีด` | Hb, MCV, RBC, RDW, Hct |
| วาฟาริน | `Warfarin` `WF` | INR และเป้า `goal 2-3` (หรือ `เป้า 2.5-3.5`) |

- **Hb และ HDL ต้องระบุเพศ** (กรอกในช่องเพศของหน้าเว็บ) ถ้าไม่ระบุ ระบบไม่แปลผล Hb และใช้เกณฑ์ HDL ของผู้ชายพร้อมบอกแพทย์
- **INR ถ้าไม่เขียน `goal`** ระบบใช้เป้าตั้งต้น 2.0-3.0 และบอกแพทย์ว่าใช้ค่าตั้งต้น (เป้าจริงขึ้นกับข้อบ่งชี้) ระบบ **ไม่แนะนำขนาดยา**
- **ข้อความผลตรวจในบรรทัดโรค (tags):** คำที่ระบบรู้อยู่ใน `data/lexicon.json` หมวด `tags` เพิ่มคำเองได้ · คำนำหน้า `no` `ไม่มี` `ไม่พบ` ทำให้เป็น 'ไม่มี' (เช่น `no hydro`) · คำที่ไม่รู้จะแสดงเป็น 'ไม่เข้าใจ' ไม่ถูกเดา
- **Thai CV risk:** ระบบไม่คำนวณ ให้คำนวณจากเครื่องมือเองแล้วกรอกในช่อง 'Thai CV risk' ของหน้าเว็บ (ออฟไลน์ได้) ระบบจะแจ้งแพทย์ว่าบันทึกมีข้อมูลครบสำหรับคำนวณหรือไม่
- ตัวอย่าง: `Warfarin : INR 1.8->2.4->2.9 goal 2-3` · `CBC : Hb 9.2 MCV 68 RBC 4.9 RDW 17 Hct 28` · `DLP : LDL 160 HDL 35 TG 310 TC 245` · `MAFLD : ALT 85 AST 60 Plt 180 LSM 9.8kPa CAP 290dB/m` · `COPD : FEV1 55% FEV1/FVC 0.62 mMRC 2 CAT 14 Exac 1` · `Asthma : ACT 17 PEF 300 PEFbest 450` · `CKD : Cr 1.8 eGFR 38 UACR 120 U/S KUB increased echo, no hydro`

## 2) บรรทัดวันที่: `วัน/เดือน/ปี : ข้อความอิสระ`
```
22/10/69 : มีเวียนศีรษะ ฉันได้น้อย ยังสูบบุหรี่อยู่
```
- ปี 2 หลัง = พ.ศ. (`69` = 2569) ปี 4 หลัก ≥ 2400 = พ.ศ. ถ้าเป็น ค.ศ. (`2026`) ก็อ่านได้ วันที่เป็นไปไม่ได้/อนาคต/เก่ามากจะเตือน
- แยกอาการด้วย **เว้นวรรค** (หรือจุลภาค)
- รู้จัก: เลือดกำเดา/เหงือกเลือดออก/ฟกช้ำ/ถ่ายดำ/ปัสสาวะเป็นเลือด (เลือดออก; ถ้าใช้วาฟารินจะเตือนระดับสูง) · เวียนศีรษะ/เวียนหัว/มึนหัว/หน้ามืด · บ้านหมุน · ปวดศีรษะ/ปวดหัว · ใจสั่น · บวม · เหนื่อย/หอบ · ฉันได้น้อย/กินน้อย/ทานน้อย/เบื่ออาหาร · ฉันได้ดี/กินได้ปกติ · สูบบุหรี่ (ยังสูบ / เลิกแล้ว / ไม่สูบ / ไม่เคยสูบ)
- คำปฏิเสธ: `ไม่มีเวียนศีรษะ` = ไม่มี (ไม่ถูกนับเป็นอาการ)
- ใช้บรรทัดวันที่ **ล่าสุด** เป็นข้อมูลของวันนี้
- คำที่ไม่รู้จัก (เช่น `นอนไม่หลับ`) แสดงเป็น "ไม่เข้าใจ" **ไม่ถูกทิ้ง**
